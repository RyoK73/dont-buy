# アプリコンセプト

ほしいものはありますか？

ほしいものがある時、購入資金以外にも必要なものがあると私は考えています。
それは購入への心理的なハードルを超えることではないでしょうか。

お金を貯めることで購入資金はたまります。しかし果たして買っていいのか...罪悪感ともったいないという気持ちがその欲しい物への到達を阻みます。

過去にはなんども無駄な買い物・お菓子・ちょっと欲しいものを我慢してきたというのに、金額が大きくなると購入するのも躊躇してしまう。

また、貯金がなかなかできずにはいませんか？目についたほしいものを買ってしまって気づいたときにはすっからかん...なんてことも。

このアプリはそんな悩みを解決します。

アプリ上で買う予定だったものを記録することで、我慢した履歴とともに我慢した分のお金がアプリ上にたまります。もちろん現実でも買わなかった分のお金はたまります。

そうして、現実で失うはずだったお金がたまっていく。

一般的に貯金するときに重要なことは、収入から先に貯金額を分けておくことですが、このアプリのアプローチは逆、節約した金額を貯金額として記録します。

買わなかったという行為によりお金がたまります。そして我慢したんだという気持ちも蓄積されます。

その貯金額が目標に達した時、アプリを見返せばこれまでどう節約して、何を我慢したのかの履歴が見ることができます。

それにより欲しい物を買うときの心理的ハードを下げ、無理なく購入に踏み切れるでしょう。

このアプリは節約の貯金体験を提供します。
